# Stretch Reminder 🧘

## Purpose
A simple Python script that runs in the background and displays a desktop popup notification every 30 minutes, reminding you to **stand up and stretch**. Designed for students and developers who spend long hours at their computer.

## How It Works
- Uses Python's `tkinter` library (built-in, no installation needed) to show a popup window.
- Runs in a loop — after you dismiss the popup, the 30-minute timer resets automatically.
- Includes a motivational stretch tip with each reminder.

## Usage
```bash
python script.py
```
Leave the terminal open and continue working. Every 30 minutes a popup will appear!

- Python 3.x

## Why This Matters
Sitting for long periods increases risk of back pain, eye strain, and fatigue. A simple 2-minute stretch break every 30 minutes can dramatically improve your focus and health.
